이 글은 발행용이 아니라 **타이포그래피 확인용 견본**입니다. 본문에서 쓸 수 있는 요소를 전부 담았습니다. `tailwind.config.ts`의 `typography`를 고친 뒤 이 글을 열어 보면, 에디터와 발행 화면 양쪽에서 결과를 한 번에 확인할 수 있습니다. 아자

아래는 긴 문단이 어떻게 흐르는지 보기 위한 것입니다. 줄간격과 글자 크기가 편안한지, 한글과 영문이 섞였을 때 어색하지 않은지 살펴보세요. 좋은 본문은 읽는 사람이 활자를 의식하지 않게 만듭니다. The quick brown fox jumps over the lazy dog. 문장이 여러 줄로 넘어갈 때 줄과 줄 사이가 너무 붙거나 벌어지지 않는지가 특히 중요합니다.

### 제목 3 — 그 아래 단계

# 제목 1 — 본문 안에서는 드물게

본문 중간에 제목 1을 쓰는 일은 드물지만, 크기 균형을 보기 위해 넣어 둡니다.

## 문장 안의 강조

문장 안에서 **굵게**, *기울임*, ***굵은 기울임***, ~~취소선~~, 그리고 `인라인 코드`가 어떻게 보이는지 봅니다. [링크는 이렇게 보입니다](https://example.com) — 마우스를 올리면 흐려집니다. 강조가 본문 흐름을 끊지 않으면서도 눈에 들어와야 합니다.

## 인용

> 좋은 글은 고쳐 쓴 글이다. 처음부터 좋은 문장은 거의 없다.
>
> 인용이 두 문단일 때의 간격도 함께 확인합니다.

## 코드

인라인은 `const x = 1`처럼 보이고, 블록은 아래와 같습니다.

```ts
export function slugify(title: string): string {
  return title
    .trim()
    .toLowerCase()
    .replace(/[^a-z0-9]+/g, "-")
    .replace(/^-+|-+$/g, "")
    .slice(0, 80);
}
```
