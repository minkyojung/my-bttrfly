# 디스콰이엇 아카이브 문체 가이드

2024년 디스콰이엇에 연재한 글(`content/posts/disquiet-*.md`)을 개인 사이트용으로
정리할 때 따르는 규칙. 기준 글은 `disquiet-newsletter-saas.md`.

에세이·회고 글(그 외 `content/posts/*.md`)에는 적용하지 않는다.

## 1. 화자

- 인사말 없이 바로 본론으로 시작한다.
- "안녕하세요", "윌리에요", "디스콰이엇 정민교입니다" 같은 자기소개를 쓰지 않는다.
- 소속(디스콰이엇)을 화자 정체성으로 쓰지 않는다.

## 2. 말투 — 합니다체

문장 종결은 `~습니다` / `~입니다`로 통일한다.

기계적으로 바꿀 수 있는 것:

| 해요체 | 합니다체 |
|---|---|
| ~할 수 있어요 | ~할 수 있습니다 |
| ~했어요 | ~했습니다 |
| ~인 것 같아요 | ~인 것 같습니다 |

기계적으로 안 되는 것 — 연결어미가 진짜 작업이다.

| 해요체 습관 | 처리 |
|---|---|
| `~인데요,` | 문장을 끊는다. 또는 `~입니다. 그런데` |
| `~거든요` | 근거를 앞으로 빼서 `~기 때문입니다` |
| `~하고요` / `~있고요` | 앞 문장에 합치거나 `~합니다`로 끝낸다 |
| `~하는 것이죠` | `~하는 것입니다` |
| `~처럼요` | 문장으로 풀어 쓴다 |

연결어미를 끊으면 문장이 짧아지고 군더더기가 빠진다. 문체 변경이 아니라
문장 다이어트로 접근한다.

## 3. 건드리지 않는 것

- **인터뷰이 발화** — 남의 말투다. 인터뷰 글 본문은 원문 그대로 둔다.
- **인용 블록(`>`)** — 번역문, 트윗, 프롬프트 예시, 인용구 전부.
- **코드블록 안** — 프롬프트 예시와 명령어.
- **개조식 기능 설명 불릿** — 이미 문체 대상이 아니다.

인터뷰 글에서 바꾸는 것은 도입부, 요약 불릿, 그리고 글쓴이가 던진 질문 헤딩뿐이다.

질문 헤딩은 `~습니까?`로 바꾸지 않는다. 뉴스 인터뷰처럼 딱딱해진다.
합니다체 글에서도 질문은 `~나요?` / `~인가요?` / `~까요?`가 자연스럽다.
인터뷰어의 평서형 코멘트만 `~네요` / `~같아요` → `~습니다`로 바꾼다.

## 4. 문서 구조

- 본문 첫 줄에 제목을 다시 쓰지 않는다. frontmatter `title`만 쓴다.
- 디스콰이엇 플랫폼 CTA(업보트, 댓글, 큐레이션 신청, 프로덕트 리뷰 문의,
  PMC/마루 모집)는 넣지 않는다.
- 광고 표기가 있는 글의 표기 문장은 지우지 않는다.

## 5. 마크다운

- 이스케이프 잔재(`\*\*`, `\[`, `\~`, `&gt;`, `&amp;`)를 남기지 않는다.
- 링크 없는 "바로가기" 불릿을 남기지 않는다. URL을 붙이거나 지운다.
